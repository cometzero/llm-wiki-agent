## Overview
Habitat-GS (2026)는 Dynamic Gaussian Splatting을 사용한 high-fidelity navigation simulator이다. Mesh-based rasterization의 visual realism 한계를 해결하며, dynamic human avatars를 지원한다.

## Key Claims
- Dynamic Gaussian Splatting으로 시각적 사실성 달성
- Real-world scenarios로의 agent generalization 지원
- Dynamic human representations 지원
