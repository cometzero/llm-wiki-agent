## Summary
[[AndrejCarpathy]]는 고속 AI 발전 흐름 속에서 개발 방식의 정신적/운영적 전환을 설명한 인물로, [[VibeCoding]] 개념에서 AI와의 몰입형 협업이 기존 코드 이해 중심 패러다임을 어떻게 바꾸는지 제시한 점이 핵심이다.

## Key Claims
- AI와의 협업은 단순 코드 작성 자동화가 아니라, 시스템적으로 반복 가능한 결과를 만드는 작업 방식이다.
- 빠른 성능 향상이 계속될수록 사람의 역할은 코드 자체의 정밀 열람에서 의사결정, 경계 설정, 결과 검증으로 이동한다.
- 프로덕션에서의 실효성은 개인의 코드 이해력보다 관리 체계와 실험적 가설 검증 역량으로 결정된다.
