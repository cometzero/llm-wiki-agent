## Overview
ABot-N0 (2026)은 unified VLA foundation model로, 5개의 core tasks (Point-Goal, Object-Goal, Instruction-Following, POI-Goal, Person-Following)에서 "Grand Unification"을 달성한다. Hierarchical "Brain-Action" architecture를 사용하며, LLM-based Cognitive Brain이 semantic reasoning을 담당한다.

## Key Claims
- 5개 navigation task의 unified VLA model
- Brain-Action architecture: LLM Cognitive Brain + action execution
- Task-specific architecture fragmentation 문제 해결
