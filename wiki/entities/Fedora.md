# Fedora Project

Fedora는 Red Hat 후원의 커뮤니티 기반 Linux 배포판으로, 최신 기술 채택과 자유 소프트웨어 원칙 사이의 균형을 추구한다.

## Key Events (2026)

### AI Developer Desktop Controversy
2026년 3월, Red Hat 엔지니어 Gordon Messmer가 Fedora "AI Developer Desktop" 구상을 제안했다. 이 구상은 AI 개발 도구와 NVIDIA CUDA 지원을 쉽게 제공하려는 목적을 갖지만, 트리 외부 커널 모듈 지원과 LTS 커널 가능성이 Fedora의 "상류 커널을 빠르게 추적" 정책과 충돌했다.

Fedora Council은 6대 0으로 승인했으나, Justin Wheeler가 막판에 반대표로 전환하면서 합의 절차가 중단되었다.

### Key Participants
- **Gordon Messmer** — 제안자, Red Hat 선임 소프트웨어 엔지니어
- **Justin Wheeler** — Fedora Council 구성원, 합의 중단을 위한 반대표
- **Neal Gompa** — 트리 외부 모듈 정책 변경 반대
- **Jef Spaleta** — Fedora Project Leader, AI 친화적 방향 지지

## Connection to [[RedHat]]
Fedora는 Red Hat의 전략적 압력 아래 AI 친화 방향으로 이동하고 있으며, 이는 커뮤니티 자율성과 기업 후원의 긴장을 보여준다.
