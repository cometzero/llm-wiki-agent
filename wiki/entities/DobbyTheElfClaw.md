## Summary
[[DobbyTheElfClaw]]는 가정 자동화를 위해 구성된 개인형 지속형 에이전트 사례로, 로컬 네트워크의 장치 제어, 알림, 환경제어 통합을 통해 [[agent-first software]]의 사용자 경험 전환을 보여준다.

## Key Claims
- 앱 중심 흐름 대신 API 중심 제어로의 이동을 상징하는 실제 예시.
- 센서·액추에이터 제어와 알림 자동화가 결합된 소프트웨어 사용성의 전환점을 제시.
