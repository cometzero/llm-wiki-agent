# GB300

NVIDIA의 GPU. OmniDreams의 real-time inference에 사용.

## Performance
- Single unit: 2B model 68 FPS (single camera)
- 16 units: 4-camera 105 FPS

## Context
GB300 기반의 real-time 수치는 일반 연구실 재현성이 낮다는 한계가 있음. 이는 OmniDreams 평가 결과 해석 시 고려해야 할 사항.
