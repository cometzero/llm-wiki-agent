# Julien Voisin

보안 연구자로, 2026년 Forgejo 플랫폼에서 여러 보안 취약점을 발견하고 "carrot disclosure" 방식으로 공개한 인물이다.

## Carrot Disclosure Incident
4월 29일 공개 글에서 Forgejo에서 완전한 RCE(원격 코드 실행)를 달성할 수 있다고 주장하며, 풀 리퀘스트 형태로 일부 수정을 제출했으나 보안 정책에 따른 비공개 보고는 하지 않았다.

### 그의 주장은 다음과 같다:
- "저녁 한 번을 들여 꽤 많은 취약점을 찾을 수 있었고, 그중 일부를 체이닝해 완전한 RCE를 얻을 수 있었습니다"
- 코드베이스의 "안타까운 상태"로 인해 끝없는 두더지 잡기에 의미가 없다고 판단

### 후속 조치
公开批评后，他向Forgejo 보안팀에 사과, 설명, 권고, 익스플로잇/PoC를 포함한 이메일을 발송했다.
