Microsoft is positioned as a large-scale operator in the [[ONNX]] ecosystem.

## Profile
- Uses [[ONNX]] across internal and external products.
- Uses [[ONNXRuntime]] for production inference.
- Serves as an evidence source for runtime-level performance gains in enterprise-scale workloads.

## Relevance in this source
- 적용 영역: Bing, Office 365, ML.NET, AzureML, WinML, Skype, Power BI.
- 규모: 서비스에서 수십억 건 단위 요청 처리 환경에서 [[ONNXRuntime]]을 적용하며 성능 향상을 측정.
- 대표 수치: Bing QnA/Segment QnA 최대 2.8배, Semantic Search 이미지 임베딩 1.8배 성능 향상.
