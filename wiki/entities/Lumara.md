## Profile

[[Lumara]] is used in the keynote as an example enterprise deployment of [[ClaudeManagedAgents]].

## Key Claims

- Presented as a “virtual startup” test case for [[MultiAgentOrchestration]] with roles such as commander, detector, and navigator.
- The agent team used markdown-based success criteria and repeated grading loops to improve task success.
- Demonstrated drone operation simulation quality improvements through [[Outcomes]] + [[Dreaming]] loops.

## Connections

- [[MultiAgentOrchestration]] — structural decomposition into agent roles.
- [[Outcomes]] — success criteria defined by explicit acceptance conditions.
- [[Dreaming]] — post-run learning for future simulation runs.
- [[Claude Managed Agents]].
