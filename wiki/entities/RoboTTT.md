# RoboTTT

[[RoboTTT]]는 robot policy history를 deployment 중 gradient update되는 fast weight에 압축해 long visuomotor context를 확장하는 접근이다. [[PonderPounce]]가 transformer causal context/carrier state를 쓰는 것과 대조되는 memory substrate다.
