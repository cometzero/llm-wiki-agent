## Overview
Linux 커널 개발자로, "spawn template" 패치 세트를 제출하여 fork()/exec() 패턴 최적화를 제안한 인물이다.

## Key Work
- 커널에 spawn_template_create() 및 spawn_template_spawn() 시스템 호출 제안
- 동일한 실행 파일을 반복 실행하는 애플리케이션의 성능 개선 목표
- Christian Brauner의 pidfd 기반 API 방향에 동의하고 향후 작업 진행
