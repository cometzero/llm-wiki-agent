## Summary
TBD-VLA는 discrete token 기반 VLA(Vision-Language-Action) 모델에서 temporal action generation을 위해 block diffusion을 도입한 framework다. Action sequence를 temporal block으로 나누어 block 내부에서는 masked discrete diffusion으로 병렬 denoising을 수행하고, block 사이에서는 autoregressive generation을 유지한다. 이 설계는 temporal coherence와 inference speed를 동시에 달성하며, Real-Time Chunking(RTC) 같은 asynchronous execution을 가능하게 한다.

## Key Claims
- Block discrete diffusion이 VLA에서 temporal autoregression과 parallel action decoding을 결합한다
- 0.117s latency로 OpenVLA(0.344s), VLA-0(1.980s), MolmoAct(5.633s)보다 빠른 동시에 temporal modeling 가능
- Real-World Franka manipulation에서 π0.5(50.0%) 대비 67.1% success rate 달성
- Real-Time Chunking을 통해 실행 중인 action prefix 유지하며 미래 block만 재생성 가능

## Architecture Details
### Backbone: [[Qwen3-VL]] 2B
TBD-VLA는 Qwen3-VL 2B를 backbone으로 사용하며, tokenizer에 mask token, placeholder token, action token을 추가한다.

### Prompt Template
```
State: {state tokens}, Task: {instruction}, Actions: {placeholder tokens}
```

### Core Factorization
```
p(a_1:H | o, g) = Π_k pθ(a_{km+1:(k+1)m} | o, g, a_{1:km})
```

### Temporal-level Token Shift
VLM의 autoregressive 성질과 block diffusion objective를 정렬하기 위해 현재 action block의 logits가 다음 block을 예측하도록 학습한다.

### Block-level Attention Masking
Clean/partially masked block을 병렬 처리하면서도 future block 정보 누출을 막는 custom attention mask 적용.

- `m=4, n_d=2, expectation sampling`: 88.7%, 0.086s, 4 passes
- `m=1` (near full AR): 84.6%, 0.223s, 16 passes
- `m=16` (near full diffusion): 84.0%
