## Summary
ABot-N1은 VLM이 직접 wheel command를 내리는 대신 pixel goal을 생성하고 fast action expert가 continuous waypoint로 grounding하는 slow-fast VLA/VLN 구조를 제안한다. 다섯 navigation task(point/object/POI/instruction/person-following)를 하나의 goal-conditioned framework로 통합하며, indoor 95.4%, outdoor 92.9%, POI arrival 77.3% SR을 달성했다.

## Key Claims
- Slow VLM reasoner가 CoT와 pixel goal을 생성하여 cognition/control decoupling 실현
- Fast action expert가 pixel guidance와 text cue를 continuous waypoint로 변환
- Pixel goal intermediate representation으로 semantic reasoning과 executable action 사이의 명확한 interface 제공
- Closed-loop performance를 특히 강조하며 simulation 및 real-world urban-scale navigation SOTA 달성
- VLA taxonomy에서 Explicit Action Guidance + Numerical Action Generator 사이에 위치

## Key Quotes
> "general navigation에서 semantic reasoning, long-tail robustness, continuous control, interpretability를 동시에 만족하기 어렵다"

> "language/representation이 어떻게 action으로 grounded되는가를 직접 다룬다"

## Architecture / Pipeline
```
Visual observations + Navigation history + Goal(Instruction/Object/POI/Point/Person)
    ↓
Slow VLM Reasoner (CoT reasoning + Pixel goal generation)
    ↓
Fast Action Expert (pixel-to-waypoint conversion)
    ↓
Continuous Waypoints → Robot Navigation Controller
    ↓
New observations → Loop
```

## Key Concepts
- [[PixelGoal]]: VLM이 생성하는 image-space anchor로, 언어 reasoning과 연속 제어 사이의 bridging representation
- [[SlowFastArchitecture]]: 고수준 reasoning(VLM)과 저수준 execution(Action Expert)의 분해
- [[Waypoint]]: continuous navigation을 위한 연속 좌표 포인트
- [[ActionGrounding]]: 언어/픽셀 표현이 어떻게 물리적 실행 가능성으로 변환되는지
- [[ClosedLoopNavigation]]: model output이 다음 상태 분포를 바꾸는 상황에서 error accumulation과 safety 확인

## Training Recipe
- Pretraining: paper-specific dataset mixture 또는 logged traffic/trajectory data
- Post-training: task reward, closed-loop rollout, GRPO/entropy regularization
- 핵심: representation을 action으로 바로 내보내지 않고 중간 guidance(pixel goal 또는 flow action)를 물리적 실행 가능성에 맞게 변환

## Benchmarks & Metrics
- VLN-CE: R2R, RxR
- OVON (Object Nav)
- ABotN-PointBench, ABotN-POIBench
- EVT-Bench
- Real-world indoor/outdoor/urban deployment
- Metrics: SR, SPL, arrival-style metrics, robustness across task types

## Limitations
- Reported benchmark가 실제 도로 안전성 보장하지 않음
- Large VLM/flow model은 latency, memory, edge deployment 문제
- Closed-loop success가 causal safety guarantee는 아님
- Long-tail failure와 hallucinated reasoning/trajectory drift 별도 감시 필요

## Autonomous Driving Connection
Slow planner가 route/semantic intent를 만들고 fast planner가 BEV waypoint/trajectory를 생성하는 dual-system E2E AD 설계에 참고 가능. 단, pixel-space anchor를 차량 BEV/map coordinate로 옮길 때 calibration과 safety envelope 중요.
