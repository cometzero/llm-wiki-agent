## Summary
HumanNet은 인간이 실제 세계와 상호작용하는 장면을 100만 시간 규모로 모은 human-centric video corpus로, 1인칭/3인칭 관점, 세밀한 활동, human-object interaction, 도구 사용, 장기 행동을 함께 포함한다. 1,000시간의 egocentric HumanNet pretraining이 100시간의 real-robot data pretraining보다 낮거나 유사한 validation loss를 보여 인간 비디오가 robot data의 비용 효율적 대체재가 될 수 있음을 보인다.

## Key Claims
- Embodied intelligence의 핵심 병목은 모델 크기가 아닌 데이터 인프라이다
- Human-centric video는 robot teleoperation만으로 수집하기 어려운 폭의 object, environment, body configuration, task variation을 제공한다
- First-person video는 actor-centered intent, hand-object contact, motor decision 이후의 시각적 결과를 담는다
- Third-person video는 full-body motion, posture, scene context, multi-agent dynamics를 더 잘 보여준다
- 1,000시간 HumanNet egocentric pretraining은 100시간 real-robot CoBot data와 유사/이하 validation loss를 달성한다

## Key Quotes
> "진보하는 embodied intelligence는 이제 모델 크기보다 데이터 인프라 병목에 더 강하게 묶여 있다" — Introduction

> "HumanNet은 단순히 '큰 비디오 모음'이 아니라, physical AI pretraining을 위한 데이터 인프라로 설계한다" — Introduction

## Design Principles

| 원칙 | 의미 | VLA 관점의 중요성 |
|---|---|---|
| Scale | activity/environment/motion/action style의 long-tail을 덮을 만큼 커야 함 | rare behavior가 representation learning에 포함됨 |
| Viewpoint diversity | first-person과 third-person을 모두 보존·색인 | actor intent와 scene dynamics를 함께 학습 |
| Physical relevance | hand-object proximity, body motion, state change, action ordering 유지 | action grounding의 원천 |
| Pretraining readiness | chunking, metadata, filtering, captions, motion annotations | VLM/VLA post-training mixture로 바로 사용 가능 |

## Validation Experiments

LingBot-VLA architecture를 고정하고 pretraining source만 바꾸는 controlled experiment:
1. Generic Qwen-based VLM
2. Qwen VLM + 100시간 real-robot CoBot data adaptation
3. Qwen VLM + 1,000시간 HumanNet egocentric video adaptation
4. LingBot: 20,000시간 real-robot training

모든 variant는 동일 downstream corpus(100 tasks, task당 20 episodes, 총 34시간)로 post-training.

## Data Pipeline

1. **Data Collection**: seed keyword 확장, keyword/channel crawling, existing source integration
2. **Data Processing**: de-duplication, normalization, filtering, scene splitting, clipping
3. **Annotation**: 3D hand/body pose detection, monocular SLAM, motion retargeting, LLM-assisted captioning

Robot-ready subset 기준: retargeting error < 15mm, valid-frame coverage ≥ 60%

## Limitations
- Embodiment gap: 인간 손/몸/도구 사용과 robot control space 사이의 차이
- Scale의 noise: label ambiguity, inconsistent task boundary, missing metadata
- Privacy와 safety: bystander, private interior, identifiable people 포함 가능
