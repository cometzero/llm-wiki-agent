# S-Agent

[[S-Agent]]는 spatial tool use를 통해 reasoning을 유도하는 에이전트 계열이다. 공간 질문을 풀 때 외부 도구를 적극적으로 활용하는 설정을 취한다.

## Relation to SMA
- [[SpatialMemoryAgent]]와 비교하면 tool use 기반 reasoning의 대안이다.
- SMA는 도구 의존도를 낮추고, 경험 메모리 재사용으로 공간 추론을 보정한다.
