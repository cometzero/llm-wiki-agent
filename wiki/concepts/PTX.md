# PTX

PTX (Parallel Thread Execution) is NVIDIA CUDA's virtual-machine instruction set and assembly-like intermediate representation. CUDA GPU code is lowered to PTX before being assembled into architecture-specific [[CUBIN]] binaries or JIT-compiled by the CUDA driver at runtime.

## Why it matters
- PTX decouples high-level CUDA or DSL compiler output from specific NVIDIA GPU hardware ISAs.
- Embedding PTX in a [[Fatbin]] allows binaries to run on newer GPU compute capabilities that did not exist when the application was built.
- PTX can also be generated by non-CUDA language frontends, including DSLs such as [[Triton]].

## Caveats
Direct PTX authoring gives expert developers low-level control, but it is usually reserved for highly optimized inner loops because high-level CUDA or DSL code is more maintainable.
