## Summary
[[ASMR]]는 "Agent Search Memory Retriever"의 약어로, 기존 [[RAG]]의 한계를 완화하기 위해 대화 맥락에서 의미 단위를 분해하고, 정보 관계를 정제해 에이전트가 더 필요한 정보만 가져오도록 설계된 메모리·검색 프레임워크로 요약된다.

즉, 입력 토큰의 불필요 증가를 줄이는 것을 목표로 하지만, 추론 루프 반복이 늘어나면 총 토큰 처리량은 오히려 증가해 전체 수요 측면에서는 반대 효과를 낼 수 있다.

## 핵심 메커니즘
- 의미 단위 분할(에피소드/어휘 블록 단위)으로 정보 압축.
- 정보 관계 추적(유효성, 업데이트 여부, 추론 확장성) 후 정제 제공.
- 에이전트 분업화: 검색·판단·결합 단계로 파이프라인화.

## 메모리 수요 관점
- 단기: 불필요 토큰 감소로 효율 개선 기대.
- 총량: 재조회·추론반복 증가로 토큰 총량과 추론 길이가 증가하면 하드웨어 메모리 수요 확대 요인으로 작동 가능.
