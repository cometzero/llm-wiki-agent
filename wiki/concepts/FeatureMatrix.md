# Feature Matrix

[[FeatureMatrix]]는 머신러닝에서 sample과 feature를 행렬 형태로 나타낸 데이터 표현이다.

## Core Idea
- 보통 row는 sample, column은 feature를 뜻한다.
- 입력 데이터의 구조를 정리해 모델 학습과 연산을 가능하게 한다.
- 딥러닝에서는 [[Tensor]]로 확장되어 더 복잡한 shape를 가진다.

## Connections
- [[FunctionApproximation]] — 함수가 받는 입력 표현
- [[Tensor]] — 더 일반적인 다차원 표현
