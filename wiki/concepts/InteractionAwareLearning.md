HumanNet이 제안한 학습 패러다임으로, 인간-물체 상호작용의 의미론적 구조를 이해하여 robot-relevant representation을 학습한다.

**데이터 특성:**
- Object manipulation activity
- Tool use patterns
- Human-object contact dynamics
- State change sequences

**[[VLA]] 학습에서의 역할:**
- Language-video alignment의 물리적 기반
- Action primitives 추출
- Task structure 이해

**연관:**
- [[HumanNet]] — 제안된 데이터셋
- [[MotionAwareLearning]] — 결합하여 사용
- [[HumanCentricVideo]] — 데이터 소스
