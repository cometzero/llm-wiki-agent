## Definition
A feature map is the output produced when a convolution kernel is applied across an input. Each position stores how strongly the kernel's learned pattern appears at that location.

## Relevance
CNN layers usually produce multiple feature maps, one per learned kernel or output channel, representing different visual patterns such as edges, textures, or object parts.
