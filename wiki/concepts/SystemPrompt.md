## Definition
A system prompt is a high-priority instruction layer that sets an [[LLM]]'s overall role, behavioral rules, safety constraints, and response style.

## In AI Systems
System prompts are commonly paired with user prompts, retrieved context from [[RAG]], and tool instructions from [[ToolUse]]. They define the stable frame within which individual requests are answered.

## Related Concepts
- [[PromptEngineering]] — includes system-level and task-level prompting
- [[InstructionDesign]] — specifies work rules and output requirements
- [[PromptSensitivity]] — system prompt wording can affect outputs
