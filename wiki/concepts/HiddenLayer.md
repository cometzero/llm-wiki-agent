## Summary
A [[HiddenLayer]] is an intermediate layer between a model's input and output layers. In a [[MultiLayerPerceptron]], hidden layers transform raw inputs into hidden representations that can make the final prediction easier.

## Connections
- [[MultiLayerPerceptron]] — MLPs contain one or more hidden layers.
- [[ActivationFunction]] — typically applied after hidden layer linear calculations.
- [[RepresentationLearning]] — hidden layers create learned intermediate representations.
