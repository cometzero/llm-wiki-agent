# Mem0

[[Mem0]]는 production-ready AI agents를 위한 scalable long-term memory를 다루는 계열이다. 사용자/에이전트 상태를 장기적으로 관리하는 실용적 메모리 레이어에 가깝다.

## Relation to SMA
- [[SpatialMemoryAgent]]보다 더 일반적인 agent memory 관리 축이다.
- SMA는 generic memory보다 verifier-grounded spatial procedure의 재사용을 강조한다.
