## Definition

[[Claude Managed Agents]] is a managed service pattern that combines [[Claude]] model capabilities, orchestration primitives, and production controls.

## Core Properties

- Faster prototype-to-production path.
- Shared memory and session consistency.
- Orchestration and evaluation hooks for complex workflows.
- Integration with higher-level application stacks via [[API]] primitives.

## Why It Matters

The keynote frames this as a key bridge from research-grade AI capability to enterprise operations, especially for tasks requiring repeated, auditable execution.
