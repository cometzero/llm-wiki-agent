## 1. BASIL: 품질 관리 플랫폼 업데이트 및 로드맵

BASIL은 테스트 추적성, 요구사항 매핑, 규정 준수 문서화를 위한 품질 관리 플랫폼으로, 최근 사용자 편의성과 효율성을 높이는 다양한 기능이 추가되었다.

### 1.1. BASIL 소개 및 주요 업데이트
1. **BASIL은 ELISA의 품질 관리 플랫폼이다**
    1. BASIL은 Red Hat에서 ISO 26262 자동차 배포판의 규정 준수를 위해 개발되었다.
    2. 이 도구는 ELISA의 GitHub에서 호스팅되며, ELISA 웹사이트에서 공개 인스턴스를 사용할 수 있다.
2. **최근 몇 달간 BASIL에 추가된 주요 기능들**
    1. **PDF 및 HTML 내보내기 지원**: 커뮤니티의 요청에 따라 PDF 및 HTML 형식으로 문서를 내보낼 수 있게 되었다.
    2. **계층적 문서 매핑**: BASIL의 일반적인 작업 항목인 문서 매핑 기능을 확장하여, 작업 항목들의 계층적 매핑을 생성할 수 있다.
    3. **작업 항목 포크 기능 확장**: 모든 작업 항목 유형에 대해 포크(fork) 기능을 확장하여, 기존 작업 항목을 재사용하면서도 변경 사항을 반영하고 추적성을 유지할 수 있다.
    4. **UI에서 작업 항목 삭제 가능**: 이전에는 불가능했던 UI를 통한 작업 항목 삭제 기능이 추가되어, 사용하지 않는 항목을 데이터베이스에서 제거할 수 있다.
    5. **손상된 매핑 자동 수정**: 코드 변경으로 인해 매핑이 깨질 경우, BASIL이 자동으로 매핑을 수정하여 수동 작업을 줄여준다.
        1. 예를 들어, C 파일의 함수 위치가 변경되어 매핑이 깨지더라도, BASIL은 동일 파일 내에서 함수를 찾아 자동으로 매핑을 복구한다.
    6. **파일 관리 개선**: 사용자 파일 섹션에서 파일을 더 효율적으로 정리하고 폴더를 생성할 수 있게 되었다.
    7. **할 일(To-Do) 주석 기능**: 작업 항목에 주석을 추가하고, 이 주석을 '할 일'로 표시하여 UI에 표시함으로써 작업 완료에 필요한 사항을 쉽게 추적할 수 있다.
    8. **새로운 동적 매핑 뷰**: 기존 매핑 뷰는 특정 작업 항목(예: 소프트웨어 요구사항, 테스트 케이스)에 초점을 맞추었으나, 새로운 동적 뷰는 모든 작업 항목을 한눈에 볼 수 있도록 하여 복잡한 매핑 관계를 단순화한다.
        1. 이 뷰는 코드 조각과 관련된 요구사항이나 작업 항목을 식별하거나, 특정 작업 항목과 관련된 참조 문서의 부분을 확인할 수 있게 해준다.
        2. 이는 향후 AI 기반 질의응답 기능(MCP 서버, AI 스킬) 개발을 위한 준비 단계이기도 하다.

### 1.2. 향후 BASIL 개발 로드맵
1. **테스트 자동화 프레임워크 통합**: Red Hat의 테스트 자동화 프레임워크인 **Jumpstarter**와의 통합을 지원할 예정이다.
    1. Jumpstarter는 보드 프로비저닝, 랩 구성, 테스트 자동 실행을 위한 솔루션으로, 이미 자동차 회사에서 사용 중이다.
    2. Jumpstarter는 Red Hat의 또 다른 도구인 **Test Management Tool (TMT)**을 테스트 실행 프레임워크로 사용한다.
    3. BASIL은 현재 TMT를 포함하여 GitLab CI, GitHub Actions, Kernel CI, Test Team Farm, Lava와 같은 다양한 테스트 실행 플러그인을 지원하며, 다음으로 Jumpstarter를 지원할 계획이다.
        1. GitLab CI 및 GitHub Actions의 경우, CI 환경에서 실행된 테스트 결과를 BASIL에 참조하여 테스트 케이스와 연결하고 추적성을 확보할 수 있다.
2. **SPDX 3.1 안전 프로필 지원**: SPDX 3.1 안전 프로필로의 마이그레이션 또는 진화를 지원할 계획이다.
    1. ELISA는 현재 SPDX 3.1 준수를 위한 많은 격차를 식별하고 이를 해결하기 위해 노력하고 있다.
    2. 예를 들어, 여러 작업 항목이 함께 다른 작업 항목의 완료율을 어떻게 나타낼지 등 중요한 논의가 진행 중이다.
3. **MCP 서버 및 AI 스킬 지원**: MCP 서버와 AI 스킬 지원을 통해 BASIL과의 상호작용을 개선할 예정이다.
    1. MCP 서버는 재현성이 높아 신뢰할 수 있는 반면, AI 스킬은 도구 사용 방식에 대한 더 많은 정보를 제공할 수 있다.
    2. 두 가지 솔루션을 모두 지원하는 방향으로 개발될 가능성이 높다.
4. **참여 방법**: BASIL 프로젝트에 참여할 수 있는 다양한 방법이 있다.
    1. GitHub를 통해 코드 개발에 참여할 수 있다.
    2. Discord의 'tool working group' 채널에서 논의에 참여할 수 있다.
    3. 'tool investigation' 메일링 리스트를 활용할 수 있다.
    4. 데모를 요청하여 BASIL에 대해 더 자세히 알아볼 수 있다.
