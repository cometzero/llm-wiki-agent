# EAGLE-3: LLM 추론 가속화를 위한 혁신적 스케일링 기술

EAGLE-3는 대규모 언어 모델(LLM)의 추론 속도를 획기적으로 향상시키기 위해 설계된 새로운 기술입니다. 기존 EAGLE 방식이 데이터 확장에 따라 성능이 비례해서 늘어나지 않던 한계를 극복하고, 훈련 데이터 양에 따라 추론 속도가 가속화되는 '스케일링 법칙'을 실현했습니다.

## 1. 핵심 혁신 기술

EAGLE-3의 주요 변화는 기존의 특징 예측(Feature Prediction) 제약을 제거하고 직접적인 토큰 예측과 다층 특징 융합을 도입한 것입니다.

### 가. 훈련 시간 테스트 (Training-Time Test)

기존 EAGLE은 다음 단계의 특징(Feature)을 예측하는 데 집중했으나, 이는 모델의 표현력을 제한했습니다. EAGLE-3는 이를 제거하고 직접 토큰을 예측하며, 훈련 중에 실제 추론 과정을 시뮬레이션하는 '훈련 시간 테스트' 기법을 사용합니다.

Draft Model - Transformer Layer

### 나. 다층 특징 융합 (Multi-layer Feature Fusion)

타겟 모델의 최상위 레이어 특징만 사용하던 방식에서 벗어나, 저레벨, 중레벨, 고레벨의 특징을 모두 결합하여 더 풍부한 의미 정보를 활용합니다. [110]

### 주요 성과

최대 6.5배 속도 향상: 기존 EAGLE-2 대비 약 1.4배 더 빠른 성능을 기록했습니다. [13]

추론 가속의 스케일링 법칙: 훈련 데이터가 늘어날수록 추론 속도가 비례하여 빨라지는 현상을 최초로 발견했습니다. [67]

높은 수용률 유지: 단계가 진행됨에 따라 수용률이 급격히 떨어지던 기존 방식과 달리, EAGLE-3는 안정적인 수용률을 유지합니다. [196]
