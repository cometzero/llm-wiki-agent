## 1. 엔비디아 그루트(NVIDIA GR00T): 휴머노이드용 파운데이션 모델 [1]

엔비디아 그루트는 휴머노이드 로봇을 위한 범용 AI 모델로, VLM 기반의 상위 이해와 확산 트랜스포머 기반의 하위 행동 생성을 결합한 이원 구조를 사용하며, 다양한 데이터를 피라미드 형태로 엮어 학습하고, 여러 로봇 몸체에 적용 가능한 파운데이션 모델을 목표로 한다.

### 1.1. 그루트 N1: 범용 로봇 AI의 기본 뼈대 제시 [9]

범용 로봇을 위한 세 가지 축 [14]

범용 로봇의 자율성을 위해서는 좋은 몸체, 거대한 모델만으로는 부족하며, 하드웨어, 모델, 데이터의 세 가지 축이 함께 필요하다고 엔비디아는 강조한다. [15]

특히 인간 환경에서 범용적으로 일할 수 있는 플랫폼으로 휴머노이드가 유리하며, 그 위에서 작동할 일반화된 로봇 모델이 필요하다고 설명한다. [17]

데이터 피라미드 전략 [18]

휴머노이드의 실제 동작 데이터는 매우 비싸고 희소하며, 단일 로봇 실기체 데이터만으로는 진정한 제너럴리스트 모델을 만들기 어렵다는 문제 인식에서 출발한다. [19]

그루트는 학습 데이터를 아래층에서 위층으로 갈수록 데이터 양은 줄어들지만, 인바디먼트 특이성은 커지는 피라미드 구조로 본다. [22]

맨 아래층에는 웹 기반의 비전 언어 데이터와 인간의 이고센트릭 비디오 같은 대규모 데이터가 있다. [23]

중간층에는 시뮬레이션이나 신경망 기반 생성 기법으로 만든 신세틱 트레젝토리가 있다. [23]

맨 위층에는 실제 로봇에서 얻은 텔레 오퍼레이션 데이터가 놓인다. [23]

아래층 데이터는 로봇에게 세상과 행동에 대한 넓은 사전 지식을 제공하고, 위층 데이터는 그 지식을 실제 로봇의 몸에 맞게 접지시키는 역할을 한다. [24]

듀얼 시스템 디자인 (시스템 1 & 시스템 2) [25]

그루트 N1은 자신을 비전 랭기지 액션(VLA) 모델이라고 정의하며, 이미지 관측과 언어 지시를 입력받아 로봇의 모터 액션을 출력한다. [26]

시스템 2 (VLM 백본): 비전과 언어를 통해 현재 상황과 명령을 해석하는 역할을 한다. [29]

엔비디아 이글 2 VLM을 사용하며, 인터넷 규모의 비전 언어 사전 학습을 바탕으로 시각 장면과 언어 명령을 함께 해석한다. [31]

VLM의 마지막 층 출력이 아닌 중간층 리프레젠테이션을 사용했는데, 이는 더 빠르고 정책 성능도 더 좋았기 때문이다. [33]

중간층 표현은 아직 지나치게 언어화되기 전 단계의 정보로, 장면의 구조, 물체의 위치 관계, 동작과 연결되기 쉬운 특징을 잘 유지하여 행동 정책 모듈에 더 직접적으로 쓸모 있다. [38]

시스템 1 (디퓨전 트랜스포머 기반 액션 모듈): 시스템 2의 해석 결과를 바탕으로 실제 모터 명령을 빠르게 생성한다. [29]

플로우 매칭과 액션 청킹을 사용하여, 짧은 시간 동안 이어질 여러 개의 동작을 하나의 묶음으로 예측한다. [43]

이는 매 순간 다시 계산하느라 동작이 끊기거나 흔들리는 문제를 줄이고 더 부드럽고 일관된 움직임을 만든다. [45]

액션 묶음은 디퓨전 계열 방식으로 생성되며, 노이즈가 섞인 초안에서 출발해 점차 정교한 동작 시퀀스로 정제된다. [47]

시스템 1은 시스템 2의 VLM이 이해한 결과를 크로스 어텐션을 통해 참고하며 동작을 생성한다. [49]

인바디먼트 스페시픽 엔코더와 디코더 [53]

로봇마다 몸의 형태와 제어 방식이 다르기 때문에, 공통의 지능 구조를 유지하면서도 각 인바디먼트에 맞는 입력 해석기와 출력 변환기를 따로 두어 서로 다른 로봇의 상태와 액션 차원을 처리하도록 설계되었다. [53]

그루트 N1은 처음부터 싱글 암 로봇부터 바이매뉴얼 덱스트러스 핸즈까지 다양한 인바디먼트를 하나의 구조 안에서 다루는 것을 목표로 한다. [60]

이는 상위의 멀티모달 이해와 하위 행동 생성 프레임은 공유하고, 인바디먼트 스페시픽 부분만 최소한으로 분리하는 파운데이션 모델적 사고를 반영한다. [61]

액션 없는 데이터 활용 전략 [63]

그루트는 사람의 1인칭 시점 영상이나 AI가 생성한 영상처럼 로봇 조종을 위한 정확한 동작 정보가 없는 데이터도 학습에 활용한다. [64]

잠재 행동 코드북과 역동역학 모델을 이용해 가상의 동작 정보를 유추하고 이를 로봇 학습에 활용하여 행동 프라이어를 확장한다. [66]

이 전략을 통해 자체 텔레 오퍼레이션 데이터 8시간을 827시간 규모의 카운터 팩투얼 로봇 트레젝토리로 확장했다. [69]

성능 검증 [71]

시뮬레이션에서 BC 트랜스포머, 디퓨전 폴리시 같은 베이스라인보다 일관되게 우세한 성능을 보였다. [72]

특히 사전 학습을 충분히 거친 크로스 인바디먼트 파운데이션 모델이 제한된 포스트 트레이닝 데이터 조건에서도 기존 이미테이션 러닝 베이스라인보다 우세하여, 파운데이션 모델식 사전 학습이 로봇 제어에서 실제 효용을 가짐을 입증했다. [76]

### 1.2. 그루트 N1.5: VLM 처리 방식 개선 및 그라운딩 능력 강화 [77]

VLM 처리 방식 개선 [82]

N1.5는 엔비디아 디글 계열 VLM을 사용하지만, 학습 과정에서 VLM 자체를 크게 다시 학습시키지 않고 프리즈(freeze) 한 채 사용했다. [85]

이는 VLM 전체를 함께 학습시키면 계산 비용이 커지고 시각 언어 이해 능력이 불안정해질 수 있기 때문에, 이미 잘 학습된 VLM은 그대로 두고 그 출력을 로봇 행동 모듈이 더 잘 활용하도록 연결부를 다듬는 실용적인 선택이다. [87]

비전 엔코더와 LM 사이를 잇는 어댑터 구조를 단순화하고, 비주얼 토큰과 텍스트 토큰 임베딩에 레이어 노멀라이제이션을 추가하여 서로 다른 두 정보를 더 안정적으로 섞고 모델이 둘을 더 자연스럽게 함께 해석하도록 만들었다. [91]

이러한 변화는 랭귀지 팔로잉과 제너럴라이제이션을 크게 개선하여, 사용자의 언어 지시를 더 잘 따르고 학습되지 않은 상황에도 유연하게 대응하게 되었다. [96]

그라운딩 능력 강화 [99]

N1.5의 VLM은 디글 2.5에서 출발하여 더 나은 그라운딩과 피지컬 언더스탠딩을 갖도록 튜닝되었다. [100]

이는 "저 접시 옆에 빨간 사과를 집어라"와 같은 자연어 지시를 실제 물체 선택으로 연결해야 하는 로봇 문제에서 중요한 능력으로, N1.5가 랭귀지 팔로잉을 크게 끌어올린 배경이 된다. [102]

플레이어(Player) 오브젝티브 추가 [104]

N1.5는 미래 화면을 픽셀 단위로 직접 생성하는 대신, 미래 장면이 갖게 될 의미 있는 내부 표현, 즉 레이턴트 임베딩 쪽에 맞추도록 학습시키는 방식을 택했다. [108]

이는 미래 영상을 완벽하게 복원하는 것이 아니라, 조금 뒤에 어떤 상태가 될지 핵심적인 특징만 맞춰보라고 학습시키는 것으로, 모델이 겉모습을 그리는 능력보다 미래 변화를 이해하는 능력에 더 집중하게 된다. [110]

이 접근 방식은 로봇 정책 학습과 직접 연결되는데, 로봇 정책은 현재 행동을 하면 잠시 뒤 어떤 상태가 될지를 잘 예측할수록 더 좋은 결정을 내릴 수 있기 때문이다. [112]

또한, 이 방식은 사람의 시연 영상에 로봇의 정확한 관절값이나 액션 레이블이 없더라도, 영상 속 시간 흐름 자체에서 다음에 어떤 상태가 오는가를 배우는 데 활용될 수 있어 휴먼 비디오 활용 가능성을 넓혀준다. [115]

### 1.3. 그루트 N1.6: 복잡한 작업 및 다양한 인바디먼트 확장 [120]

확장된 초점 [120]

N1.6은 랭귀지 팔로잉 개선뿐만 아니라, 더 복잡한 리얼 월드 바이매뉴얼 테스크와 로코 매니큘레이션, 그리고 더 다양한 인바디먼트 확장에 초점을 맞춘다. [121]

데이터 측면의 확장 [122]

N1.5까지의 데이터 믹스처에 더해, 바이매뉴얼 암스, AGI 보진원 시뮬레이티드, 갤럭시아 R1프온 비헤이얼 유닛, 트리 지원 홀바디 로코 매니큘레이션에서 수집한 수천 시간 규모의 텔레오퍼레이티드 데이터를 추가했다. [123]

이는 N1에서 제시된 크로스 인바디먼트 파운데이션 모델 개념을 더 본격적으로 밀어붙이며, 복수 플랫폼과 더 어려운 전신 작업으로 확장하는 단계에 들어선 것을 의미한다. [124]

엔비디아는 N1.6이 N1.5보다 다양한 인바디먼트에서 더 나은 포스트 트레이닝 성능을 보였으며, 사용자들이 바이매뉴얼 매니큘레이션과 로코 매니큘레이션에서 더 나은 출발점을 얻을 것이라고 설명한다. [125]

그루트 계열의 핵심 정리 [126]

VLM 기반의 상위 이해와 DI의 하위 행동 생성을 결합한 이원 구조를 가진다. [127]

웹 데이터, 인간 영상, 신세틱 트레젝토리, 실기체 데이터를 하나의 피라미드로 엮는 데이터 전략을 사용한다. [128]

크로스 인바디먼트 어댑테이션을 전제로 한 파운데이션 모델 관점을 취한다. [129]

이 세 가지를 합쳐야 휴머노이드용 파운데이션 모델이라는 말이 성립하며, 그루트는 휴머노이드라는 인바디먼트 위에서 멀티모달 이해, 행동 생성, 데이터 확장 전략, 일반화 실험을 하나의 프레임으로 묶은 첫 번째 본격적 공개 사례에 가깝다. [129]

N1은 기본 뼈대를 제시했고, N1.5는 그라운딩과 랭귀지 팔로잉, 휴먼 비디오 활용 가능성을 높였으며, N1.6은 더 큰 모델과 더 다양한 인바디먼트, 더 복잡한 작업으로 확장했다. [131]

## 2. 구글 제미나이 로보틱스(Google Gemini Robotics): 생각하는 AI를 실제 로봇 행동으로 연결하려는 시도 [132]

구글 제미나이 로보틱스는 멀티모달 AI의 이해와 추론 능력을 물리 세계의 행동으로 연결하는 것을 목표로 하며, 추론 계층과 행동 계층을 분리하고, 행동 전에 생각하는 구조와 로봇 몸체 간 동작 지식 전이 기술을 통해 범용 로봇 AI를 구현한다.

### 2.1. 제미나이 로보틱스 초기 버전: 추론과 행동의 분리 [132]

핵심 목표: 멀티모달 AI의 이해와 추론을 물리 세계 행동으로 연결 [133]

2025년 3월 첫 보고서는 이 문제를 정면으로 다루었으며, 2025년 9월 제미나이 로보틱스 1.5는 생각한 뒤 행동하는 구조와 서로 다른 로봇 몸체 사이에서 동작 지식을 옮기는 구조까지 본격적으로 추진했다. [134]

제미나이 로보틱스 가족: 두 축의 역할 분담 [135]

제미나이 로보틱스 (VLA 모델): 카메라로 본 장면과 사람이 준 지시문을 받아 실제 로봇이 실행할 행동 명령으로 이어주는 모델이다. [136]

제미나이 로보틱스 ER (인바디드 리즈닝): 로봇의 손목을 직접 움직이는 저수준 제어기라기보다 장면 속 물체의 위치와 관계를 이해하고, 무엇을 먼저 해야 할지 계획을 세우고, 필요한 경우 코드를 생성해 기존 제어기와 연결하는 상위 지능에 가깝다. [138]

구글은 처음부터 하나의 거대한 엔드투엔드 모델만 밀어붙이기보다 추론 계층과 행동 계층을 역할에 맞게 나눠 설계했음을 알 수 있다. [140]

클라우드 백본 & 로봇 온보드 액션 디코더 구조 [141]

로봇은 사람이 채팅창에서 답변을 기다리듯 몇 초씩 멈춰 있을 수 없으므로, 모델의 똑똑함만큼이나 지연 시간이 매우 중요하다. [141]

구글은 대형 모델 추론을 로봇 내부에서 돌리기 어렵다는 점을 인정하고, VLA 백본은 클라우드에 두되 로봇 위에는 빠르게 반응하는 액션 디코더를 따로 두는 방식을 택했다. [142]

이 구조에서 원시 관측으로부터 저수준 액션 청크까지의 엔드투엔드 지연은 약 250ms 수준이며, 여러 액션을 묶음으로 예측하는 액션 청킹을 사용해 실효 제어 주파수는 50Hz 수준까지 맞춘다. [143]

액션 청크는 짧은 구간의 행동 묶음을 한꺼번에 예측하는 방식으로, 느린 거대 모델을 쓰더라도 로봇은 좀 더 부드럽고 안정적으로 움직일 수 있게 한다. [144]

초기 강조점: 범용성, 상호 작용성, 손재주 [146]

범용성: 새로운 환경이나 처음 보는 물체에도 어느 정도 대응하는 능력이다. [147]

상호 작용성: 사람이 도중에 말을 바꾸거나 물체 위치가 바뀌어도 반응을 수정할 수 있는 능력이다. [148]

손재주: 정교한 조작 능력이다. [149]

구글은 제미나이 로보틱스가 기존 VLA 대비 일반화 성능을 크게 끌어올렸다고 설명한다. [150]

초기 한계: 생각과 행동 간 간극 [151]

제미나이 2.0 계열의 인바디드 리즈닝 능력만으로는 로봇 코드 생성이나 퓨샷 제어는 가능했지만, 정교한 조작에서는 성공률이 충분히 높지 않았다. [152]

예를 들어, 알로하 2에서의 실제 실험 결과, 제로샷에서는 바나나 전달 같은 과제는 일부 되지만 옷 접기처럼 더 정교한 조작은 거의 수행하지 못했다. [153]

반면, 인컨텍스트 러닝(몇 개의 시범 예시를 문맥 안에 넣어주는 방식)에서는 성능이 크게 올라갔는데, 이는 생각만 잘하는 모델과 손을 잘 쓰는 모델 사이에 아직 간극이 있음을 보여준다. [154]

### 2.2. 제미나이 로보틱스 1.5: 생각-행동 분리 및 모션 전이 강화 [155]

세 가지 혁신 [155]

모션 트랜스퍼(Motion Transfer): 서로 다른 로봇 몸체 사이에서도 동작 학습을 옮길 수 있도록 설계되었다. [156]

씽킹 비포 액팅(Thinking Before Acting): 행동 전에 자연어 기반의 내부 추론 과정을 끼워 넣는다. [156]

제미나이 로보틱스 ER 1.5의 인바디드 리즈닝 강화: 공간 이해와 상위 계획 능력을 더욱 강화했다. [156]

씽킹 비포 액팅 (행동 전에 생각하기) [158]

전통적인 VLA가 지시문에서 행동으로의 직접 매핑에 가깝다면, 제미나이 로보틱스 1.5는 이 사이에 자연어 기반의 내부 추론 과정을 끼워 넣는다. [159]

이를 멀티레벨 인터널 리즈닝 프로세스라고 설명하며, 예를 들어 "빨래를 색깔별로 나눠라"는 지시를 받으면, 모델은 곧바로 팔을 움직이는 대신 작업을 정리하고, 하위 단계 계획을 세우며, 미세 행동 수준까지 내려간다. [161]

이 구조 덕분에 긴 작업을 더 짧고 성공 가능성이 높은 구간으로 나눌 수 있고, 사람 입장에서도 로봇이 왜 저 행동을 하는지 조금 더 해석 가능해진다. [161]

이 씽킹 능력은 복잡한 멀티스텝 테스크 해결을 돕고 의사 결정을 더 투명하게 만든다. [162]

이는 체인 오브 닷과 유사하지만, 일반 LM에서의 추론이 답변 품질을 높이기 위한 것이라면, 여기서는 실제 물리 행동을 안정적으로 수행하기 위한 중간 구조라는 점이 다르다. [164]

모션 트랜스퍼 (동작 전이) [167]

로봇마다 관절 수, 팔 길이, 센서 위치 등이 다르기 때문에 기존 로봇 학습은 특정 로봇에서 모은 데이터가 해당 로봇에만 유효하기 쉬웠다. [168]

제미나이 로보틱스 1.5는 이 문제를 해결하기 위해 서로 다른 인바디먼트, 즉 서로 다른 로봇 몸체 사이에서도 동작 학습을 옮길 수 있도록 설계되었다. [170]

이는 앞으로의 병목이 모델 구조만이 아니라 데이터 수집 비용이기 때문에 매우 중요한 포인트이다. [171]

모션 트랜스퍼가 잘되면 특정 인바디먼트에서 어렵게 모은 데이터를 다른 인바디먼트 학습에도 활용할 수 있게 된다. [173]

제미나이 로보틱스 ER 1.5 강화 [174]

ER 모델은 손을 직접 움직이는 손놀림의 달인이라기보다 공간 이해와 상위 계획의 전문가에 가깝다. [175]

2025년 3월 보고서는 이미 2D 객체 검출, 특정 지점 가리키기, 2D 트레젝토리 예측, 탑다운 그래스 예측, 멀티뷰 코리스폰던스, 3D 바운딩 박스 디텍션 같은 능력을 깊게 분석했다. [176]

구글은 로봇 문제에서 앞단의 공간적 이해를 매우 중요한 축으로 보고 있었으며, 제미나이 로보틱스 1.5에 와서는 이 인바디드 리즈닝 쪽이 더 강화되었다. [178]

ER 1.5는 "더 퍼스트 씽킹 모델 옵티마이즈드 포 인바디드 리즈닝"이라고 표현되며, 15개 학술 벤치마크에서 스테이트 오브 더 아트 성능을 보였다. [180]

ER 1.5는 현재 장면에서 무엇을 해야 할지 계획을 세우고, 진행 상황을 추정하며, 필요하면 구글 서치 같은 도구를 호출하는 상위 두뇌 역할을 맡는다. [182]

즉, 1.5세대에서 구글은 VLA 하나로 모든 것을 끝내기보다, ER 1.5가 계획하고 제미나이 로보틱스 1.5가 실행하는 에이전트 프레임워크를 더 분명하게 내세웠다. [183]

엔비디아 그루트와의 유사점 [184]

과거 알티투류의 연구가 인터넷 지식을 행동으로 옮길 수 있다는 가능성을 보여줬다면, 제미나이 로보틱스 1.5는 생각하는 상위 에이전트와 실행하는 하위 정책을 명시적으로 나눠가는 방향을 보여준다. [184]

특히 ER 1.5가 계획, 도구 사용, 진행도 추정까지 맡고, GR 1.5가 실제 액션을 담당한다는 점은 엔비디아의 시스템 2, 시스템 1 분리와 상당히 닮아 있다. [186]

### 2.3. 제미나이 로보틱스 연구의 핵심 포인트 [187]

좋은 로봇 AI는 행동 모델 하나만으로 완성되지 않는다. [188]

장면을 이해하는 능력, 물체와 공간의 관계를 파악하는 능력, 작업을 쪼개는 계획 능력, 그리고 실패했을 때 다시 시도하는 상호 작용성이 함께 필요하다. [189]

대형 모델을 로봇에 쓰려면 지능만큼 시스템 구조가 중요하다. [190]

2025년판의 클라우드 백본, 온로봇 디코더 구조나 1.5의 ER, VLA 협업 구조는 모두 현실적인 로봇 시스템을 의식한 결과이다. [191]

범용성을 확보하기 위해 가장 중요한 것은 데이터와 인바디먼트 문제이다. [192]

모션 트랜스퍼가 중요한 이유도 여기에 있으며, 앞으로는 로봇을 잘 움직이는 모델보다 서로 다른 로봇과 환경에 빠르게 옮겨 붙는 모델이 더 큰 가치를 갖게 될 가능성이 크다. [193]

## 3. 피지컬 인텔리전스 파이(Physical Intelligence π): 범용 정책 중심 접근 [195]

피지컬 인텔리전스 파이 계열은 특정 로봇이 아닌 여러 종류의 로봇과 작업에 공통으로 통하는 범용 로봇 정책, 즉 로봇 파운데이션 모델을 목표로 하며, VLA 모델을 기반으로 데이터 일반화, 강건성, 효율성을 높이고, 계층적 구조와 지식 보존 전략을 통해 실제 환경에서의 적용 가능성을 확장한다.

### 3.1. 파이(π): 범용 로봇 정책의 출발점 [195]

핵심 철학: 범용 로봇 파운데이션 모델 [197]

피지컬 인텔리전스 팀은 처음부터 특정 로봇 하나를 잘 움직이는 전형 정책보다 여러 종류의 로봇과 여러 작업에 공통으로 통하는 범용 로봇 정책, 즉 로봇 파운데이션 모델을 목표로 삼아왔다. [197]

어떤 로봇이든 어떤 작업이든 수행할 수 있는 모델을 만들겠다고 말하며, 인간처럼 새로운 환경에 가도 이전 경험을 발판삼아 빨리 적응하는 로봇을 만들고 싶다는 것이 핵심 철학이다. [199]

파이(π) 논문의 핵심 [201]

파이 논문의 정식 제목은 "어 비전 랭귀지 액션 플로우 모델 포 제너럴 로봇 컨트롤(A Vision-Language-Action Flow Model for General Robot Control)"로, 카메라로 본 장면과 자연어 명령을 받아 실제 로봇 행동으로 이어주는 VLA 모델이다. [201]

논문 서두에서 파이는 로봇 학습의 병목을 데이터 일반화, 강건성으로 짚고, 이를 해결하기 위해 인터넷 규모의 비전 언어 사전 학습 지식을 끌어오고 여러 로봇과 여러 작업의 데이터를 함께 학습하는 구조를 제안한다. [203]

파이의 구조는 사전 학습된 비전 언어 모델 백본 위에 액션 익스퍼트를 붙여 로봇 고유의 상태와 행동을 처리하는 것이 핵심이다. [204]

이는 인터넷에서 학습된 시각 언어 지식을 최대한 활용하면서도 실제 로봇 제어에 필요한 부분은 별도의 행동 모듈이 담당하게 만든 것이다. [205]

액션 생성 방식: 플로우 매칭 [206]

액션 생성 방식으로는 당시 VLA 쪽에서 많이 쓰던 단순 자기 회귀 토큰 예측 대신 플로우 매칭을 사용한다. [206]

플로우 매칭은 연속적인 행동 궤적을 조금씩 정제하면서 만들어내는 계열에 속하며, 로봇 제어에서 중요한 손끝의 미세한 움직임이나 짧은 시간 동안의 연속 행동과 같은 연속성 있는 출력을 다루기에 유리하다. [207]

파이 논문은 이 방식 덕분에 최대 50Hz 수준의 고주파 액션 청크를 다룰 수 있고, 빨래 접기나 박스 조립처럼 정교하고 연속적인 작업에 적합하다고 설명한다. [209]

초기 한계 [211]

디퓨전이나 플로우 계열의 연속 액션 생성은 강력하지만, 학습과 추론 비용이 작지 않고, 언어 지시를 안정적으로 따르면서도 빠르게 학습시키는 것은 또 다른 문제였다. [211]

그래서 2025년의 파이는 이 계열을 한 번에 하나씩 보강해 나간다. [212]

### 3.2. 패스트(Fast): 액션 토큰화 효율성 증대 [213]

문제 의식: 자기 회귀형 VLA의 한계 [214]

자기 회귀형 VLA는 로봇의 행동을 한 번에 길게 만들어내지 않고, 마치 문장을 한 토큰씩 생성하듯 현재까지의 정보와 직전 액션을 바탕으로 다음 액션을 순서대로 예측해 나가는 방식이다. [216]

이런 방식은 언어 모델과 구조적으로 잘 맞고 구현도 비교적 단순하다는 장점이 있다. [218]

하지만 로봇의 움직임은 본질적으로 연속적인 신호인데, 이를 언어 토큰 다루듯 너무 잘게 쪼개 버리면 인접한 액션들끼리 거의 비슷한 정보가 반복되기 쉽다. [220]

결국 모델은 중요한 장기적 변화나 동작의 구조를 배우기보다 바로 직전 값과 거의 비슷한 다음 값을 맞추는 데 많은 용량을 쓰게 되어 학습이 비효율적이게 되고, 길어진 시퀀스를 다룰수록 오차가 누적되거나 전체 동작의 부드러운 흐름을 잡기 어려워질 수 있다. [223]

해결책: 주파수 영역 압축을 통한 토큰화 [225]

패스트는 로봇 액션 시퀀스를 주파수 영역에서 압축하는 방식으로 토큰화하고, 이를 통해 파이형 패스트를 학습시켰다. [226]

그 결과 복잡한 조작 성능은 파이형 수준을 유지하면서도 학습 시간을 약 5배 줄일 수 있었다. [227]

즉, 패스트는 연속 액션의 강점과 토큰 기반 학습의 효율 사이를 잇기 위한 방법이다. [228]

### 3.3. 파이 0.5: 오픈월드 일반화 및 계층적 구조 도입 [230]

오픈월드 일반화(Open-World Generalization) [231]

파이 0.5는 단순한 덱스트러스 컨트롤 모델에서 한 단계 더 나아가, 열린 세계에서의 일반화를 목표로 한다. [231]

이는 로봇이 연구실 안의 익숙한 물체만 다루는 것이 아니라, 실제 새로운 집, 새로운 배치, 새로운 물체, 새로운 표현을 만나도 어느 정도 일을 해내야 한다는 의미이다. [233]

파이 0.5는 파이를 바탕으로 여러 로봇 데이터와 고수준 의미 예측, 웹 데이터 등을 함께 공동 학습하여 더 넓은 일반화를 얻었다. [234]

특히 오브젝트 디텍션, 시멘틱 서브테스크 프레딕션, 로우 레벨 액션스 같은 이질적인 신호를 한 모델 안에서 함께 다루는 하이브리드 멀티모달 이그잼플 구성이 강조된다. [235]

이 논문은 완전히 새로운 집에서도 부엌이나 침실 정리처럼 긴 수평선의 정교한 작업을 수행하는 엔드투엔드 학습 시스템을 처음으로 보였다고 이야기한다. [236]

계층적 구조(Hierarchical Design) 도입 [237]

파이 0.5 이후부터 파이 계열은 계층적 구조를 가져가기 시작했으며, 이는 이후 공개된 파이 0.6 모델에서도 계승된다. [238]

계층 구조란 고수준에서는 어떤 하위 작업을 해야 하는지 의미적인 서브 테스크를 예측하고, 저수준에서는 실제 액션 청크를 생성하는 식으로 역할을 나누는 것을 뜻한다. [239]

로봇의 긴 작업은 단순히 손을 잘 움직인다고 해결되지 않으므로, "침실을 정리하라"와 같은 추상적인 지시를 "베개를 집는다", "이불을 펴 정리한다"와 같은 하위 단계로 나누는 능력이 필요하다. [241]

다시 말해, 파이는 파이 0.5 이후부터 상위 의미 예측과 하위 행동 생성의 분리를 더 분명히 가져가기 시작했다. [244]

### 3.4. 널리지 인슐레이션(Knowledge Insulation): 지식 보존 전략 [245]

개념: 사전 학습된 지식의 보존 [245]

널리지 인슐레이션은 사전 학습된 VLM 백본이 이미 갖고 있는 시각 언어 지식이 로봇 액션 학습 과정에서 망가지는 일을 최대한 막자는 것이다. [246]

로봇 데이터를 이용해 엔드투엔드로 다 같이 업데이트하면 언어를 잘 이해하고 시각적으로 의미를 파악하던 능력이 오히려 흐려질 수 있기 때문이다. [247]

피지컬 인텔리전스 팀은 액션 익스퍼트 쪽에서 나온 그레디언트가 백본으로 직접 흘러들어가지 않게 하는 방식 등을 통해 이를 개선했다. [248]

효과: 학습 효율 및 언어 지시 수행 능력 향상 [249]

이 전략은 제너럴리스트 모델 설정에서 중요하며, 표 버싱 작업에서 언어 지시를 더 잘 따르면서도 학습 속도는 파이 패스트만큼 빠르게 유지할 수 있었다. [249]

반대로 순수 파이 0 계열은 비슷한 수준에 도달하는 데 훨씬 더 많은 학습 스텝이 필요했다. [250]

즉, 널리지 인슐레이션은 로봇이 행동을 배우는 과정에서 이미 배운 언어 시각 지식을 잃지 않게 하는 장치이다. [251]

### 3.5. 파이 0.6: 최신 세대의 구조와 성능 [252]

최신 주력 세대: 파이 0.5의 계층 구조 계승 및 강화 [252]

파이 0.6은 파이 0.5 위에 쌓아올린 최신 VLA 모델로, 파이 0.5의 계층 구조를 유지한 채 더 강한 성능을 내도록 비전 언어 백본, 프롬프트 설계, 학습 데이터 구성을 변경했다. [253]

모델 구조 [255]

비전 언어 백본은 시그립과 잼마 3사비를 기반으로 하며, 여기에 약 860밀리언 파라미터 규모의 액션 익스퍼트가 붙는다. [256]

입력으로는 최대 네 장의 이미지, 언어 프롬프트, 프로프리오셉티브 스테이트(로봇 자신의 몸 상태 정보), 그리고 선택적으로 메타데이터까지 들어간다. [257]

백본은 패스트 액션 토큰이나 웹 같은 공동 학습 신호를 다루고, 액션 익스퍼트는 연속적인 실제 동작을 예측한다. [260]

액션 익스퍼트의 그레디언트가 백본으로 직접 흘러가지 않도록 설계되어 있는데, 이는 널리지 인슐레이션 철학이 반영된 결과이다. [261]

파이 0.6은 H 한 장에서 세 개 카메라 입력 기준 약 ms 안에 액션 청크를 생성할 수 있어, 강한 일반화와 구조적 안정성을 추구하면서도 실시간 제어 가능성을 의식하고 있다. [262]

데이터 구성 [265]

파이 0.6은 파이 0.5의 데이터 철학을 대체로 계승한다. [266]

여러 인바디먼트에서 수집된 내부 로봇 데이터, 가정 환경에서의 모바일 논 데이터, 고수준 서브스크 프레딕션 데이터, 그리고 바운딩 박스와 키포인트 프레딕션 같은 웹 기반 멀티모달 데이터가 함께 들어간다. [267]

인바디먼트는 로봇의 몸체 형태를 의미하며, 한 팔 로봇, 두 팔 로봇, 이동식 양팔 로봇 등 서로 다른 인바디먼트를 함께 학습하는 것은 단순한 데이터 양 증가보다 더 큰 의미가 있다. [268]

파이는 일관되게 크로스 인바디먼트 학습을 강조해 왔는데, 이는 어떤 로봇에서 배운 상식과 행동 감각을 다른 로봇에도 최대한 옮기고 싶다는 뜻이다. [270]

실제 성능 [271]

정적 작업에서의 아웃 오브 더 박스 성능: 셔츠 접기, 바구니 속 빨래 접기, 박스 조립, 테이블 정리 같은 작업에서 파이 0.5보다 빨라졌고, 특히 빨래 접기와 박스 조립처럼 이전에는 고품질 파인 튜닝이 필요했던 작업에서도 실제 의미 있는 성능을 보였다. [272]

이동형 양팔 로봇에서의 작업: 빨래를 집어 바구니에 넣기, 침대 정리, 접시를 싱크대에 넣기, 서랍의 물건 넣기 같은 모바일 테스크들에서도 평균 테스크 프로그래스와 스로우풋을 개선했다. [278]

제너럴라이제이션 포커스 테스크: 새로운 물체나 새로운 언어 표현, 혹은 더 어려운 조합의 지시를 던지는 테스트에서 파이 0.5보다 전반적으로 더 건강한 개선을 보였다. [284]

"건강한 개선"은 단순히 한두 벤치마크만 잘한 것이 아니라, 여러 조건에서 전반적으로 조금씩 좋아졌다는 뉘앙스로, 실제 제품에 가까운 시스템일수록 이런 류의 개선이 더 중요하다. [287]

파이 계열 요약 [290]

파이 0은 범용 로봇 정책의 출발점이었고, 파이 0.5는 그것을 실제 열린 환경으로 끌고 왔으며, 파이 0.6은 그 위에 계층 구조와 지식 보존 전략을 더 다듬어 파인 튜닝 없이도 더 바로 쓸 수 있는 방향으로 밀어붙인 최신 세대이다. [291]

이 흐름을 보면 파이가 로봇 파운데이션 모델에서 언어를 잃지 않는 문제, 여러 몸체를 넘나드는 문제, 긴 작업을 쪼개는 문제, 실제 집 환경에서 버티는 문제를 차례대로 건드려 왔음을 알 수 있다. [291]

### 3.6. 파이 계열의 미래 확장 연구 [292]

경험으로부터 더 나아지는 VLA (RL 확장) [292]

2025년 말 공개한 파이 0.6 기반 강화 학습 연구에서 사람이 일일이 시연해 준 데이터에만 의존하는 대신, 실제 배치 경험을 통해 VLA를 개선하는 방향을 제시했다. [294]

긴 작업을 위한 메모리 구조 (MEM) [293]

2026년 3월에는 MEM(롱텀 쇼텀 메모리)을 갖춘 VLA 연구를 공개했는데, 여기서는 최근 프레임 히스토리와 장기적인 텍스트 메모리를 함께 관리하여 10분 이상 이어지는 복잡한 작업을 다루려는 방향을 보여준다. [295]

이는 아직 새로운 파이 본체 세대라기보다는 파이 0.6 이후의 확장 연구로 보는 편이 맞지만, 앞으로 파이 계열이 어디로 가고 있는지를 이해하는 데 중요하다. [296]

결론: 기억하고 경험으로 개선되는 피지컬 에이전트 [297]

즉, 파이는 기억하고 경험으로 개선되며, 더 긴 작업을 잘 수행하는 피지컬 에이전트로 발전하고 있다. [297]
