# EmbodiedMidtrain 레퍼런스/관련 연구 정리

## 1. 읽을 때 먼저 봐야 할 관련 축

### VLA / robot foundation model
- OpenVLA, π0, GR00T 계열은 VLM/LLM backbone을 action generation으로 확장하는 대표 흐름입니다.
- EmbodiedMidtrain은 이들 모델 자체의 architecture를 바꾸기보다, VLA fine-tuning 전에 VLM backbone을 어떤 데이터로 mid-training해야 하는지에 집중합니다.

### VLM backbone
- Qwen-VL/Qwen2.5-VL/Qwen3-VL, InternVL, PaliGemma, Kosmos-2 등이 baseline 또는 backbone으로 언급됩니다.
- 논문의 실험 포인트는 "더 큰 VLM이 항상 더 좋은 VLA 초기값은 아니다"입니다.

### Embodied/spatial VLM data
- RefSpatial, EmbSpatial-Bench, Robo2VLM, RoboPoint 같은 데이터는 일반 VQA보다 spatial grounding, affordance, robot-centric reasoning에 가깝습니다.
- proximity estimator는 이런 데이터의 샘플들을 상대적으로 높게 평가합니다.

### Data selection / target-guided pretraining
- LLM pretraining에서 target domain과 가까운 corpus를 고르는 아이디어를 VLM→VLA 전이에 적용한 것으로 볼 수 있습니다.
- 핵심은 dataset-level filtering이 아니라 sample-level proximity scoring입니다.

## 2. 논문에서 직접 중요한 레퍼런스 메모

- VLM4VLA (Zhang et al., 2026): 이 논문의 VLA fine-tuning/evaluation pipeline의 기반입니다. VLM backbone과 action decoder를 연결해 여러 VLM을 VLA setting에서 비교합니다.
- InternVL3.5 (Wang et al., 2025a): proximity estimator feature space와 주요 1B backbone 실험에 사용됩니다.
- Qwen3-VL (Bai et al., 2025a): cross-backbone transfer 실험에 사용됩니다.
- RefSpatial (Zhou et al., 2025): high-scoring embodied/spatial VLM data의 대표 예시입니다.
- Calvin / SimplerEnv / LIBERO: downstream manipulation benchmark입니다.
- Gretton et al. (2012): MMD(Maximum Mean Discrepancy) 측정의 통계적 배경입니다.
